# Formations et abonnements

Les choix commerciaux ont été confirmés après la première spécification :
Cameroun, XAF, Essentiel 1 100 FCFA/mois, Créatif 2 200 FCFA/mois, Complet 5 500 FCFA/mois.
Le compte marchand existant n'a pas d'accès API ; les paiements sont donc vérifiés
manuellement dans Orange Money par l'administrateur.

L'implémentation, les droits détaillés et les limites de lancement sont décrits dans
[Comptes et abonnements](memberships.md). Ce guide remplace la spécification préparatoire.

La production des vidéos reste à réaliser : démonstration d'un prompt clair, puis
personnalisation de ChatGPT, avec un compte de démonstration et des informations fictives.
Conserver une version texte autonome. Vérifier les menus de ChatGPT au moment du tournage.
